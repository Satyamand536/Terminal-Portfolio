# 🟢 Terminal Portfolio | Satyam Tiwari

> **A command-driven professional interface built with Next.js, engineered for recruiters and developers who value speed, efficiency, and terminal-first design.**

This isn't just a portfolio; it's a "Terminal as a UI" experiment. Instead of navigating with a mouse, visitors interact with my work through a keyboard-driven interface that mimics a high-performance shell like ZSH or bash.

## 🧠 Engineering Highlights

### 1. Adaptive AI Assistant (`ask`)
Built a rule-based intelligence core that processes natural language queries. It's not just a keyword matcher; it handles context, logic-based branching, and suggests relevant shell commands to guide the user through my background and projects.

### 2. High-Fidelity Terminal Experience
- **Tab Autocomplete**: Real-time command completion based on valid shell state.
- **Command History**: Arrow-key navigation (`Up`/`Down`) with a persistent session history.
- **Role-Based Access**: Specialized views for `recruiter` vs `visitor` (locked commands, unique status scans).

### 3. Config-Driven Architecture
The entire application is completely decoupled from its content. Every banner, project detail, social link, and career milestone is controlled via a single `config.json` schema, allowing for effortless content scalability.

### 4. Responsive ASCII Engine
An adaptive rendering system that swaps 80-char (desktop), 60-char (tablet), and 40-char (mobile) ASCII banners and profile art in real-time based on window breakpoints, ensuring the terminal aesthetic remains perfect on any device.
